# Getting started: the first 90 days

A realistic plan for a small or mid-sized organisation that uses AI but has not yet governed it. It assumes one person with a few hours a week, plus support from management.

## Days 1 to 30: get the picture

| Step | Output | Template |
|---|---|---|
| Name an AI Governance Lead and get management backing | Short mandate from management | |
| Find out what AI is already in use. Ask each team, check software subscriptions and the AI features in tools you already have. | First version of the AI register | [ai-register.csv](../templates/ai-register.csv) or the [AI Use Case Register](https://ai-use-case-register.streamlit.app) |
| Classify each use case: role, EU AI Act risk tier, oversight level | Governance intensity per use case | [EU AI Act Risk Check](https://ai-act-risk-check.streamlit.app), [Oversight Scale](../framework/03-oversight-scale.md) |
| Check which other laws apply to you: GDPR, NIS2, DORA | One overview, overlaps found | [Regulation Navigator](https://regulation-navigator.streamlit.app), [Regulatory map](../framework/06-regulatory-map.md) |
| Stop anything prohibited | Nothing in the register marked "stop" | |

**By day 30 you know** what you have, and where the real risks are.

## Days 31 to 60: set the rules

| Step | Output | Template |
|---|---|---|
| Write and approve the AI policy | Approved policy, published internally | [ai-policy.md](../templates/ai-policy.md) |
| Set up the AI Council, even if it is three people | Charter and first meeting | [ai-council-charter.md](../templates/ai-council-charter.md) |
| Agree roles | RACI adapted to your organisation | [Roles and RACI](../framework/05-roles-and-raci.md) |
| Start AI literacy training for all staff (Art. 4) | Training plan, first sessions held | |
| Add disclosures where Art. 50 applies (chatbots, generated content) | Notices in place | |
| Review the contracts for your most-used AI tools (with the DORA pack if you are a financial entity) | Contract gaps listed, vendor follow-up started | [AI Contract Clause Checker](https://contract-clause-checker.streamlit.app) |

**By day 60** everyone knows the rules, and there is a place to bring questions.

## Days 61 to 90: make it routine

| Step | Output | Template |
|---|---|---|
| Put the intake form into the procurement and project process | No new AI without an intake | [use-case-intake.md](../templates/use-case-intake.md) |
| Create system records for enhanced and strict use cases | Evidence in one place | [ai-system-record.md](../templates/ai-system-record.md) |
| Share the incident process, covering every reporting duty that applies to you | Staff know how to report, and who reports what | [incident-report.md](../templates/incident-report.md), Incident Clock in the [Regulation Navigator](https://regulation-navigator.streamlit.app) |
| If you have delivery teams: add AI items to the Definition of Done | Governance inside the sprint | [Agile playbook](../playbook/agile-governance.md) |
| First quarterly council review | Register reviewed, gaps listed | Quarterly review in the [AI Use Case Register](https://ai-use-case-register.streamlit.app) |

**By day 90** governance is part of how work gets done, not an extra project.

## Then

- Plan for **2 December 2027**, when deployer obligations for high-risk systems in Annex III apply.
- Review the policy and the framework every year.
- Consider ISO/IEC 42001 if customers start asking for certification.
