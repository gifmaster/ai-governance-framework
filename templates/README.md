# Templates

| Template | Use it for | Lifecycle stage |
|---|---|---|
| [AI policy](ai-policy.md) | The organisation's rules for using AI | Set up |
| [AI Council charter](ai-council-charter.md) | Setting up the decision forum | Set up |
| [Use case intake](use-case-intake.md) | Registering a new AI use case | 2 Intake |
| [AI register](ai-register.csv) | The inventory of all AI use cases. Opens in Excel or Google Sheets. | 2 to 8 |
| [AI system record](ai-system-record.md) | Evidence for enhanced and strict use cases | 5 Assess |
| [Incident report](incident-report.md) | When something goes wrong | 7 Respond |
| [Backlog items](backlog-items.md) | Governance work as ready-made agile enablers | 3 to 6 |

The fields in the intake form match the columns in the register, so an intake can be pasted straight into the register.

Prefer a working tool? The [AI Use Case Register](https://ai-use-case-register.streamlit.app) uses exactly the same columns, calculates the governance intensity, runs a health check on the whole register and produces the AI Council's quarterly review.
