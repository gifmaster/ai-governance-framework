# Kommissorium for AI-rådet: [Organisationens navn]

## Formål

AI-rådet sikrer, at [Organisationen] bruger AI i overensstemmelse med AI-politikken, lovgivningen og vores risikovillighed, uden at bremse brug med lav risiko.

## Medlemmer

| Rolle | Navn | Stemmeret |
|---|---|---|
| Formand (AI-ansvarlig) | | ✓ |
| Repræsentant for forretningen | | ✓ |
| DPO eller ansvarlig for persondata | | ✓ |
| IT eller sikkerhed | | ✓ |
| Jura (fast eller efter behov) | | Rådgivende |
| HR (ved anvendelser, der berører medarbejdere) | | Rådgivende |

> Små organisationer: Tre medlemmer er nok. En ekstern rådgiver kan dække jura eller persondata.

## Det beslutter rådet

- Godkender anvendelser med governance-intensiteten **enhanced** eller **strict** ved beslutningspunkt G2 og G3 (se [governance-intensitet](../../framework/03-oversight-scale.md#governance-intensity))
- Afgør klassifikationer, der er uenighed om
- Godkender tidsbegrænsede undtagelser fra AI-politikken
- Gennemgår AI-registeret hvert kvartal
- Foreslår ændringer af AI-politikken til direktionen

Beslutninger om anvendelser med intensiteten **light** og **standard** er delegeret til den AI-ansvarlige og rapporteres til rådet. Se [beslutningsvejen](beslutningsvej.md).

## Sådan arbejder rådet

| | |
|---|---|
| Faste møder | Hvert kvartal, 60 minutter |
| Ekstraordinære møder | Inden for [10] arbejdsdage, når en anvendelse med intensiteten strict skal afgøres |
| Beslutningsdygtighed | Formanden og to medlemmer med stemmeret |
| Beslutninger | I enighed. Er det ikke muligt, beslutter formanden, og uenigheden noteres. |
| Inhabilitet | Et medlem, der ejer den anvendelse, der skal afgøres, stemmer ikke |
| Dokumentation | Beslutninger og begrundelser registreres i AI-registeret |

## Fast dagsorden

1. Nye anvendelser til beslutning
2. Ændringer af eksisterende anvendelser (formål, data, leverandør, tilsynsniveau)
3. Hændelser siden sidste møde
4. Gennemgang af registeret: overskredne gennemgange, værktøjer fundet uden for registeret
5. Nyt om regulering
6. Status på oplæring (se [planen for AI-færdigheder](ai-kompetenceplan.md))

## Rapportering

Formanden rapporterer til [direktionen] [to gange om året] om: antal anvendelser fordelt på intensitet, hændelser, overskredne gennemgange og kommende ændringer i reguleringen.
